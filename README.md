# MoveGreen 🌱

O MoveGreen é um projeto desenvolvido com o objetivo de incentivar práticas sustentáveis por meio de um sistema moderno e intuitivo. A plataforma busca facilitar o gerenciamento e acompanhamento de ações relacionadas à sustentabilidade, promovendo organização, praticidade e conscientização ambiental.

---

## 📌 Objetivo do Projeto

O projeto foi criado para oferecer uma solução tecnológica que auxilie usuários no controle e acompanhamento de atividades sustentáveis, utilizando uma interface simples, acessível e eficiente.

---

## 🚀 Tecnologias Utilizadas

As seguintes tecnologias e ferramentas foram utilizadas no desenvolvimento do projeto:
